Backend

Arquitectura

AppModule reúne los módulos de una única API REST en NestJS. Los controladores reciben las solicitudes y delegan en servicios, que usan Prisma para consultar y escribir en PostgreSQL 17. Docker Compose arranca PostgreSQL, la API y Nginx. El contenedor de la API aplica las migraciones antes de iniciar, y Swagger describe los endpoints en /api/docs. AppModule · Compose

Decisiones de diseño

La API valida entradas con esquemas Zod o DTOs y aplica permisos con guards. Las cuentas usan bcrypt y una cookie JWT HttpOnly y SameSite=Strict. Una dirección se reutiliza por calle y altura. La cobertura combina el trazado con los tramos confirmados por calle y lado. La telemetría guarda una copia del recorrido al iniciar la prestación para que su seguimiento use ese mismo trazado. Validación · Sesión · Cobertura · Telemetría

Modelo de datos

User guarda la cuenta y puede tener un perfil Cliente. Direccion identifica un frente con coordenadas que pueden compartir varios domicilios, puntos limpios y puntos de trayecto. Los puntos limpios reciben los residuos asociados a su tipo. Un Trayecto pertenece a una localidad, guarda una línea GeoJSON y tiene puntos ordenados y tramos de cobertura. Los contratos vinculan camiones y conductores por fechas, y cada servicio vincula un camión con un trayecto y registra su progreso. Esquema Prisma

Módulos y funciones principales

  • Accounts · Auth y User
    Registro, inicio y cierre de sesión, usuario actual, gestión de cuentas, perfiles y domicilios.
  • Calles, Direcciones y Geocodificación
    Catálogo de calles y direcciones, más búsqueda por domicilio o coordenadas mediante GeoRef.
  • Puntos Limpios y Tipos
    Consulta pública y gestión por API de estaciones, tipos y residuos aceptados.
  • Trayectos y puntos de trayecto
    Localidades, edición de recorridos y tramos confirmados, y sugerencias de trazado con OSRM.
  • Camiones, conductores y contratos
    Gestión de flota y choferes, historial de asignaciones y consulta del contrato vigente.
  • Telemetría y Hoy
    Recibe posiciones de un proveedor, calcula el avance y devuelve trayectos y camiones vigentes para un domicilio del usuario.
  • Push
    Gestiona suscripciones por domicilio y encola, envía y reintenta avisos de proximidad cuando están habilitados.

Frontend

Arquitectura

Es una aplicación de una sola página hecha con React, TypeScript y Vite. main.tsx monta el router y AuthProvider. App.tsx define las pantallas públicas, el perfil y el panel de administración. Las páginas componen la interfaz con MUI y Leaflet, los hooks gestionan estado y efectos, y los servicios concentran las llamadas HTTP. Vite y Nginx reenvían rutas seleccionadas a la API. Las rutas del catálogo /puntos-limpios y /tipos-punto-limpio quedan en el frontend con la configuración incluida. Rutas · Vite · Nginx

Decisiones de diseño

Los formularios usan Zod y los servicios HTTP envían la cookie al mismo origen. ProfileGate guía a los usuarios comunes autenticados sin domicilio hacia el perfil y AdminPage exige el rol ADMIN para mostrar el panel. Hoy obtiene por separado los trayectos cubiertos y las posiciones vigentes, que vuelve a consultar cada cinco segundos mientras la pestaña está visible. Cliente HTTP · Perfil · Seguimiento

Modelo de datos

Los servicios definen tipos TypeScript para usuarios, domicilios, puntos, trayectos y flota. El frontend adapta estos datos a la vista, por ejemplo convirtiendo long de la API en lng para el mapa de puntos. El navegador guarda preferencias de domicilio y avisos, zonas y asignaciones a trayectos, y una copia del catálogo de Puntos Limpios. Las altas, ediciones y bajas de puntos y tipos hechas desde el panel se guardan en esa copia local. Catálogo remoto · Catálogo local · Zonas

Módulos y funciones principales

  • Hoy · /hoy
    Selecciona domicilio, dibuja recorridos y camiones activos y permite activar avisos mediante Web Push y un service worker.
  • Calendario · /calendario
    Muestra una imagen del cronograma y un video educativo incluidos en el repositorio.
  • Puntos Limpios · /puntos-limpios
    Muestra el mapa público, permite filtrar por tipo y ver qué materiales recibe cada punto.
  • Perfil y Registro · /perfil y /registro
    Inicio de sesión, registro, edición de perfil y gestión de domicilios.
  • Administración · /admin
    Gestiona usuarios, camiones, choferes y contratos. Incluye el editor de trayectos y tramos y las pantallas de zonas, puntos limpios y tipos.
