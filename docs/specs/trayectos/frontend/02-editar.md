# F02. Corregir un trayecto guardado

**Depende de** [F01](01-cargar-y-ver.md) y [B02](../backend/02-editar.md).

Abrir un trayecto existente en el editor y guardar las correcciones de sus puntos y su línea.

- [ ] Se puede mover, quitar y reordenar un punto. El orden se puede cambiar con controles de teclado.
- [ ] El mapa muestra el trazado actualizado para revisar antes de guardar.
- [ ] Cancelar deja intacta la versión guardada. Guardar y reabrir muestra los cambios.
- [ ] Si la API rechaza la edición, el formulario conserva los cambios para corregir o reintentar.
